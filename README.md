# Giordano Eventos

Protótipo visual do site institucional e mini CMS da Giordano Eventos.

## Esta primeira etapa inclui

- Site público responsivo com Home, Quem Somos, Serviços, Portfólio, Clientes, Equipe e Contato.
- Painel demonstrativo em `#admin`.
- Conteúdo fictício identificado explicitamente como placeholder.
- Persistência local no navegador apenas para avaliação do fluxo.

## Próxima etapa, após aprovação visual

Cloudflare Workers, D1, R2, autenticação, uploads, mensagens persistentes e domínio oficial.
